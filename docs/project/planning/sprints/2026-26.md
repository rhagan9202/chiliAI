## Goal

Every ingestion failure and empty extraction becomes visible and durable — a malformed document shows `FAILED` with a reason and a zero-entity document shows `EXTRACTED_EMPTY` in the per-KB document list, backed by a status projection whose migration is protected by a CI drift gate and instrumented with failure counters — while BL-019 closes the embeddings/vectorstore P1 hardening gap.

## Exit Criteria

- Ingest a malformed doc → it shows `FAILED` with a reason in `GET /knowledgebases/{kb_id}/documents`; ingest a zero-entity doc → it shows `EXTRACTED_EMPTY`, not a silent ready; a coordinator missing-key failure produces a per-document `DocumentsFailedEvent` and does not poison its batch (manual + automated verification on the full stack).
- `/metrics` exposes the three new ingestion counters; stage logs carry `stage=/duration_ms=/outcome=` fields.
- `make migrate-check` green locally and in CI, covering migration `0009`; `snapshots/head.sql` committed.
- Embedding cache + cost/usage tracking shipped; BL-019 flipped `done` (with the post-v1 re-scope recorded as BL-045) — leaving **BL-017 as the sole remaining P1**.
- Gates: pyright --strict clean, pytest ≥ 85% on touched packages, full green; ESLint clean/TS strict for any touched frontend; frontend-consumed contract changes regenerated (no drift).
