## Risks & Dependencies

- **R-1 — BL-017 is the cost center.** Version/merge semantics can rabbit-hole into distributed-systems territory. Mitigation: the design note (prerequisite 2) pins scope to REQ-GRAPH-001's bar **before** code starts; anything beyond (multi-writer CRDTs, full audit history) is named and deferred, not silently attempted.
- **R-2 — Integrity checks can regress ingestion throughput.** Existence validation on every relationship write adds round-trips on the hot ingestion path. Mitigation: batch the existence checks per `upsert_relationships` call; measure before/after with BL-043's `ingestion_stage` `duration_ms` logs — a regression is now visible, not anecdotal.
- **R-3 — BL-044 merge rules interact with domain-pack precedence.** The pack system has a known pointer-overrides-env precedence gotcha, and hot-swap cannot change the event transport. Mitigation: the merge ADR states precedence explicitly (base ← overlay ← env ← pointer) and the property-based tests cover the documented order; overlay loading follows the same guardrails as pack hot-swap.
- **R-4 — BL-023's migration risk is now fenced.** Any new DLQ table must refresh `snapshots/head.sql`; the BL-042 CI gate fails fast on a miss (proven live 2026-07-14 — the gate's first catch was exactly a missing snapshot).
- **R-5 — Estimate drift is systemic** (2026-25 retro; reaffirmed by 2026-26's verification pass finding two real defects in "code-complete" work). Mitigation: every committed story above was code-verified 2026-07-14, and **"code-complete, verification deferred" is treated as unproven** — each story's DoD includes its live verification in-sprint, not as a deferred pass.

## Exit Criteria

- A relationship write referencing a missing endpoint entity is **rejected** in both the in-memory and Neo4j adapters (no phantom nodes); a stale-version write surfaces a version conflict; merge behavior matches the design note — verified against the live stack, not only unit tests.
- The dev stack boots with `medicare_fraud_dev.yaml` as a minimal overlay over the base pack via `CHILI_CONFIG_OVERLAY_PATH`; unknown top-level keys are rejected; property-based merge tests green.
- A dead-lettered event is visible in durable storage and successfully re-driven through the pipeline via the replay surface on the live stack; runbook exists under `docs/runbooks/`.
- Any new migration lands with a refreshed `snapshots/head.sql` (CI `migrations` job green).
- Gates: pyright --strict clean, pytest ≥ 85% on touched packages, full green; ESLint clean/TS strict for any touched frontend; frontend-consumed contract changes regenerated (no drift).
- Backlog updated: graph.01/graph.02 → `done`, config.04 → `done`, events replay stories annotated; BL-017/BL-022/BL-023/BL-044 statuses reflected in `docs/project/planning/backlog.md`.
- **Live verification happens in-sprint per story** — no deferred verification pass (R-5).
