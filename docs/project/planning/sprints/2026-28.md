## Goal

A complete, repeatable, scripted demo of every platform capability on real CMS DE-SynPUF data: ingest → graph → live clustering/link prediction → peer/timeseries anomalies → risk → alerts → evidence packs with SHAP attribution and LLM narratives → policy intelligence → RAG chat — presented through a reshaped investigator workbench worthy of the demo.

## Verified predecessor state (code-checked survey, 2026-07-16)

Real and wired today: peerstats z-scores → `entity_derived_signals` → risk scoring → monitoring alerts → evidence packs (factor+subgraph); policy rule engine (ingest-triggered); GraphCanvas mounted in the live workbench; dashboard on live queries; DE-SynPUF/NPPES TN subset staged with 1% and full-scale ingest scripts. Gaps: GNN stage no-ops (both factories hard-code an empty `InMemoryGraphSnapshotSource`; `/analytics/gnn/clusters` always empty); timeseries anomalies API-only; explainability narrative is template joining and SHAP unwired; new analytics have no UI surface; no validated demo script. Several `docs/backlog/*.md` module stories are stale vs. code (frontend.01, monitoring.02, frontend.05) — closeout hygiene item.
