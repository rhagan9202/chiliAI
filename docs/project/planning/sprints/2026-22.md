## Acceptance criteria summary (per story — full criteria in [backlog.md](backlog.md))

- **BL-001** — `POST /rag/conversations/{id}/messages` answered by real `RagService` orchestrating embeddings + vectorstore + graph + LLM. In-memory adapter removed from non-test paths. pyright --strict clean, pytest ≥ 85% for `rag/`. e2e: ask a question, get a non-seeded answer.
- **BL-002** — Answer payload includes `citations: list[Citation]` (chunk_id, document_id, entity_id). Frontend renders citations under each assistant message with click-through to entity detail.
- **BL-003** — `GraphCanvas.tsx` mounted on `InvestigationWorkbenchPage` loading `/graph/entities/{id}/neighborhood`. Entity/relationship clicks open detail/highlight. Depth selector wired. e2e: search → click → see neighborhood. No axe regressions.
- **BL-004** — GitHub Actions runs `pip-audit` (backend) and `npm audit --omit=dev` (frontend) on PRs + nightly. Fails on HIGH/CRITICAL. Findings posted as PR check summary.
- **BL-026** — Add pytest cases that load `medicare_fraud.yaml` and `food_supply_chain.yaml` via `config/loader.py` and validate adapter wiring.
