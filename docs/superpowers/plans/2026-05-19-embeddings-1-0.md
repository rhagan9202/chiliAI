# Embeddings 1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release a synchronous embeddings 1.0 subsystem with multi-channel text and graph embeddings, architecture-safe GNN integration, separate graph/text vector indexing, and provider smoke coverage.

**Architecture:** `backend/embeddings` owns embedding models, text providers, graph-provider protocol, and multi-channel orchestration. The agent composition layer adapts `GnnServiceProtocol` to the embeddings graph-provider protocol. Vectorstore receives separate records/namespaces for text and graph channels so semantic search and graph learning do not share vector space.

**Tech Stack:** Python 3.12, Pydantic v2, pytest, ruff, pyright, optional OpenAI SDK, optional sentence-transformers, existing GNN and vectorstore service contracts.

from typing import Literal

EmbeddingChannel = Literal["text", "graph"]


class EmbeddingVector(BaseModel):
    """One embedding vector for one content item and channel."""

    content_id: str
    channel: EmbeddingChannel
    vector: list[float] = Field(default_factory=lambda: cast(list[float], []))
    model_name: str
    provider: str
    dimensions: int = Field(gt=0)
    created_at: datetime = Field(default_factory=utc_now)

    @model_validator(mode="after")
    def _validate_vector(self) -> EmbeddingVector:
        if not self.vector:
            raise ValueError("EmbeddingVector requires a non-empty vector.")
        if len(self.vector) != self.dimensions:
            raise ValueError(
                "EmbeddingVector dimensions must match the vector length."
            )
        return self


class GraphEmbeddingBatch(BaseModel):
    """Graph embedding vectors returned by a graph provider."""

    vectors: dict[str, list[float]] = Field(
        default_factory=lambda: cast(dict[str, list[float]], {})
    )
    model_name: str
    provider: str
    dimensions: int = Field(gt=0)


class GraphEmbeddingStatus(BaseModel):
    """Status for optional graph embedding generation."""

    requested: bool = False
    provider_configured: bool = False
    missing_content_ids: list[str] = Field(default_factory=list[str])
    failure_message: str | None = None

class EmbeddingResult(BaseModel):
    request_id: str
    vectors: dict[str, list[float]] = Field(
        default_factory=lambda: cast(dict[str, list[float]], {})
    )
    metadata: EmbeddingMetadata
    items: list[EmbeddingVector] = Field(default_factory=list[EmbeddingVector])
    graph_status: GraphEmbeddingStatus | None = None

    @model_validator(mode="after")
    def _validate_vectors(self) -> EmbeddingResult:
        if not self.vectors and not self.items:
            raise ValueError("EmbeddingResult requires at least one vector.")
        if not self.items:
            self.items = [
                EmbeddingVector(
                    content_id=content_id,
                    channel="text",
                    vector=list(vector),
                    model_name=self.metadata.model_name,
                    provider=self.metadata.provider,
                    dimensions=self.metadata.dimensions,
                    created_at=self.metadata.created_at,
                )
                for content_id, vector in self.vectors.items()
            ]
        if not self.vectors:
            self.vectors = {
                item.content_id: list(item.vector)
                for item in self.items
                if item.channel == "text"
            }
        if not self.vectors:
            raise ValueError("EmbeddingResult requires at least one text vector.")
        return self
```

from collections.abc import Sequence

from embeddings.adapters.protocols import GraphEmbeddingProviderProtocol
from embeddings.models import GraphEmbeddingBatch


class _GraphProvider(GraphEmbeddingProviderProtocol):
    def __init__(
        self,
        *,
        vectors: dict[str, list[float]],
        dimensions: int = 3,
        exc: Exception | None = None,
    ) -> None:
        self._vectors = vectors
        self._dimensions = dimensions
        self._exc = exc
        self.calls: list[tuple[str, list[str], int]] = []

    def get_node_embeddings(
        self,
        *,
        knowledge_base_id: str,
        content_ids: Sequence[str],
        dimensions: int,
    ) -> GraphEmbeddingBatch:
        self.calls.append((knowledge_base_id, list(content_ids), dimensions))
        if self._exc is not None:
            raise self._exc
        return GraphEmbeddingBatch(
            vectors={key: list(value) for key, value in self._vectors.items()},
            model_name="gnn-spectral",
            provider="gnn",
            dimensions=self._dimensions,
        )

def _embed_graph_channel(
    self,
    request: EmbedRequest,
    embedding_request: EmbeddingRequest,
) -> tuple[list[EmbeddedItem], GraphEmbeddingStatus | None]:
    if not request.include_graph_embeddings:
        return [], None
    if request.knowledge_base_id is None:
        if request.require_graph_embeddings:
            raise EmbeddingProviderError(
                "Graph embeddings require knowledge_base_id."
            )
        return [], GraphEmbeddingStatus(
            requested=True,
            provider_configured=self._graph_embedding_provider is not None,
            missing_content_ids=[item.id for item in embedding_request.items],
            failure_message="knowledge_base_id is required for graph embeddings.",
        )
    if self._graph_embedding_provider is None:
        if request.require_graph_embeddings:
            raise EmbeddingProviderError("Graph embeddings require a graph provider.")
        return [], GraphEmbeddingStatus(
            requested=True,
            provider_configured=False,
            missing_content_ids=[item.id for item in embedding_request.items],
        )
    try:
        batch = self._graph_embedding_provider.get_node_embeddings(
            knowledge_base_id=request.knowledge_base_id,
            content_ids=[item.id for item in embedding_request.items],
            dimensions=request.graph_embedding_dimension,
        )
    except Exception as exc:
        if request.require_graph_embeddings:
            raise EmbeddingProviderError("Failed to generate graph embeddings.") from exc
        return [], GraphEmbeddingStatus(
            requested=True,
            provider_configured=True,
            missing_content_ids=[item.id for item in embedding_request.items],
            failure_message=str(exc),
        )
    return _graph_items_from_batch(
        batch,
        requested_ids=[item.id for item in embedding_request.items],
        expected_dimensions=request.graph_embedding_dimension,
        require_graph_embeddings=request.require_graph_embeddings,
    )
```

```python
def _graph_items_from_batch(
    batch: GraphEmbeddingBatch,
    *,
    requested_ids: Sequence[str],
    expected_dimensions: int,
    require_graph_embeddings: bool,
) -> tuple[list[EmbeddedItem], GraphEmbeddingStatus]:
    missing_ids: list[str] = []
    items: list[EmbeddedItem] = []
    for content_id in requested_ids:
        vector = batch.vectors.get(content_id)
        if vector is None:
            missing_ids.append(content_id)
            continue
        if len(vector) != expected_dimensions or batch.dimensions != expected_dimensions:
            if require_graph_embeddings:
                raise EmbeddingProviderError(
                    "Graph embedding dimension did not match the request."
                )
            missing_ids.append(content_id)
            continue
        items.append(
            EmbeddedItem(
                content_id=content_id,
                vector=list(vector),
                channel="graph",
                model_name=batch.model_name,
                provider=batch.provider,
                dimensions=batch.dimensions,
            )
        )
    if missing_ids and require_graph_embeddings:
        raise EmbeddingProviderError(
            "Graph provider returned missing graph embeddings for: "
            + ", ".join(missing_ids)
        )
    return items, GraphEmbeddingStatus(
        requested=True,
        provider_configured=True,
        missing_content_ids=missing_ids,
    )
```

def test_embeddings_module_does_not_import_sibling_modules() -> None:
    offenders: list[str] = []
    for path in _python_files(EMBEDDINGS_ROOT):
        names = _imported_names(path)
        for name in names:
            if name in FORBIDDEN_EMBEDDINGS_IMPORT_PREFIXES or name.startswith(
                tuple(f"{prefix}." for prefix in FORBIDDEN_EMBEDDINGS_IMPORT_PREFIXES)
            ):
                offenders.append(f"{path.relative_to(BACKEND_ROOT)} imports {name}")

    assert offenders == []


def test_provider_sdk_imports_stay_behind_adapters() -> None:
    openai_offenders: list[str] = []
    sentence_transformers_offenders: list[str] = []

    for path in _python_files(BACKEND_ROOT):
        names = _imported_names(path)
        if any(name == "openai" or name.startswith("openai.") for name in names):
            if path not in APPROVED_OPENAI_IMPORT_FILES:
                openai_offenders.append(str(path.relative_to(BACKEND_ROOT)))
        if any(
            name == "sentence_transformers" or name.startswith("sentence_transformers.")
            for name in names
        ):
            if path not in APPROVED_SENTENCE_TRANSFORMERS_IMPORT_FILES:
                sentence_transformers_offenders.append(str(path.relative_to(BACKEND_ROOT)))

    assert openai_offenders == []
    assert sentence_transformers_offenders == []


def _python_files(root: Path) -> list[Path]:
    return [
        path
        for path in root.rglob("*.py")
        if not any(part in IGNORED_PARTS for part in path.parts)
    ]


def _imported_names(path: Path) -> set[str]:
    tree = ast.parse(path.read_text(encoding="utf-8"))
    names: set[str] = set()
    for node in ast.walk(tree):
        if isinstance(node, ast.Import):
            names.update(alias.name for alias in node.names)
        elif isinstance(node, ast.ImportFrom) and node.module is not None:
            names.add(node.module)
    return names

```python
"""Composition adapter from GNN analysis to embeddings graph provider."""

from __future__ import annotations

from collections.abc import Sequence

from analytics.gnn.protocols import GnnServiceProtocol
from analytics.gnn.service_models import GnnAnalysisRequest
from embeddings.adapters.protocols import GraphEmbeddingProviderProtocol
from embeddings.models import GraphEmbeddingBatch

__all__ = ["GnnGraphEmbeddingProvider"]


class GnnGraphEmbeddingProvider(GraphEmbeddingProviderProtocol):
    """Expose GNN node embeddings through the embeddings-local protocol."""

    def __init__(
        self,
        gnn_service: GnnServiceProtocol,
        *,
        model_name: str = "gnn-spectral",
        provider: str = "analytics.gnn",
    ) -> None:
        self._gnn_service = gnn_service
        self._model_name = model_name
        self._provider = provider

    def get_node_embeddings(
        self,
        *,
        knowledge_base_id: str,
        content_ids: Sequence[str],
        dimensions: int,
    ) -> GraphEmbeddingBatch:
        response = self._gnn_service.analyze(
            GnnAnalysisRequest(
                knowledge_base_id=knowledge_base_id,
                embedding_dimension=dimensions,
            )
        )
        requested = set(content_ids)
        vectors = {
            content_id: list(response.node_embeddings[content_id])
            for content_id in content_ids
            if content_id in requested and content_id in response.node_embeddings
        }
        return GraphEmbeddingBatch(
            vectors=vectors,
            model_name=self._model_name,
            provider=self._provider,
            dimensions=dimensions,
        )
```

# Embeddings

`embeddings` owns synchronous text embedding generation and multi-channel embedding artifacts.

## Boundaries

Application code depends on `EmbeddingsServiceProtocol` from `embeddings.protocols`.
Text provider adapters implement `EmbedderProtocol`.
Graph embeddings enter through `GraphEmbeddingProviderProtocol`; `embeddings` does not import `analytics`, `graph`, `vectorstore`, `api`, or `agent`.

- `openai` only in `embeddings/adapters/openai_adapter.py` and tests.
- `sentence_transformers` only in `embeddings/adapters/sentence_transformers_adapter.py` and tests.

## Channels

1.0 supports:

- `text`: semantic embeddings for RAG, semantic search, and citations.
- `graph`: GNN/node embeddings for graph similarity and clustering workflows.

Text and graph vectors are separate records. They may have different dimensions.
RAG query embedding and retrieval use the `text` channel by default.

Graph embeddings are optional. When requested, `EmbeddingsService` calls a configured `GraphEmbeddingProviderProtocol`.

Missing graph vectors are omitted by default and reported in `graph_status`.
Set `require_graph_embeddings=True` on a request to make missing or malformed graph vectors fail the request.
