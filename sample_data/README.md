# sample_data/ — local bulk source data (gitignored)

This directory holds **large, public CMS reference datasets** used to exercise the
ingestion pipeline against realistic inputs. It is **not checked into git** (see
`sample_data/*` in the repo-root `.gitignore`; only this README is tracked).

> **Read [`docs/testing/DATA.md`](../docs/testing/DATA.md) first** — it is the single
> source of truth for all test/sample data, the fixture index, and the canonical
> layout. This file is just the bulk-data drop zone.

## Canonical layout (what the builder + demo read)

```
sample_data/
├── npidata_pfile_<dates>.csv          # NPPES NPI registry (~11 GB) — builder --nppes-root
├── pl_/othername_/endpoint_pfile…     # NPPES aux (optional)
└── CMS/                                # builder --desynpuf-root
    ├── DE1_0_2008_Beneficiary_Summary_File_Sample_1.csv
    ├── DE1_0_2009_Beneficiary_Summary_File_Sample_1.csv
    ├── DE1_0_2010_Beneficiary_Summary_File_Sample_1.csv
    ├── DE1_0_2008_to_2010_Inpatient_Claims_Sample_1.csv
    ├── DE1_0_2008_to_2010_Outpatient_Claims_Sample_1.csv
    ├── DE1_0_2008_to_2010_Carrier_Claims_Sample_1A.csv
    ├── DE1_0_2008_to_2010_Carrier_Claims_Sample_1B.csv
    ├── DE1_0_2008_to_2010_Prescription_Drug_Events_Sample_1.csv
    └── tn_subset/                      # generated by the builder (--output-root)
```

NPPES files live at the **root** of `sample_data/`; DE-SynPUF files live under
`sample_data/CMS/`. (Earlier docs mentioned a `sample_data/NPPES/` subdir — that was
never the contract the code uses; ignore it.)

## How to populate it

Don't place files by hand. Download the public CMS archives (see
[`docs/testing/DATA.md` → Where to get the source data](../docs/testing/DATA.md#where-to-get-the-source-data)),
then run from the repo root:

```bash
CMS_DOWNLOADS_DIR=/path/to/your/downloads make data-setup
make demo-tn-subset
```

`make data-setup` extracts the downloaded zips into the layout above (idempotent).

## Why gitignored

The DE-SynPUF carrier files are ~1 GB each and the NPI file is ~11 GB — far over
GitHub's limits, and publicly re-downloadable from CMS. Versioning them here adds no
value. **For tracked test inputs, use the small fixtures under `backend/tests/.../fixtures/`**
(see the fixture index in `docs/testing/DATA.md`). Never put real PHI/PII here.
